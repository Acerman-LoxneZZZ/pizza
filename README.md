# FARO — 3D-сайт пиццерии

Демонстрационный сайт с настоящей 3D-пиццей и движением камеры при прокрутке. Камера приближается, облетает пиццу на 200° и завершает движение крупным планом. Используются Three.js, GSAP и ScrollTrigger. Код и ресурсы загружаются локально, платных сервисов нет.

Это рабочий прототип. Исходная текстура бесплатного скана имеет размер 1024×1024; восстановление до 4096×4096 не заменяет настоящую детализацию для экстремального макро.

## Запуск

Из корня репозитория:

```sh
python -m http.server 8765 --bind 127.0.0.1 --directory assets/pizza-video
```

Затем откройте http://127.0.0.1:8765/scene-3d/. Для просмотра не нужно устанавливать npm-зависимости или Blender. Требуется браузер с WebGL 2.
